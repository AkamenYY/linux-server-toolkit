# linux-server-toolkit

Набор скриптов и документации для администрирования Linux-серверов.

> Статус: в разработке. Полное описание проекта появится по мере реализации
> функциональности.

## Быстрый старт

```bash
git clone <url-репозитория>
cd linux-server-toolkit
./scripts/sysinfo.sh
```

## Доступные скрипты

| Скрипт | Назначение | Периодичность |
|--------|------------|---------------|
| `scripts/sysinfo.sh` | Диагностическая сводка о состоянии сервера | по требованию |
| `scripts/backup.sh` | Резервное копирование с ротацией по сроку хранения | ежедневно, 03:30 |
| `scripts/healthcheck.sh` | Контроль дисков, памяти и служб по порогам | каждые 15 минут |

## Мониторинг

`healthcheck.sh` возвращает код 3 при обнаружении отклонений, что позволяет
подключить его к любой системе мониторинга без дополнительных обёрток.
