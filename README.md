# linux-server-toolkit

Набор скриптов и документации для администрирования Linux-серверов.

> Статус: в разработке. Полное описание проекта появится по мере реализации
> функциональности.

## Быстрый старт

```bash
git clone <url-репозитория>
cd linux-server-toolkit
./scripts/sysinfo.sh
```

## Доступные скрипты

| Скрипт | Назначение | Запуск |
|--------|------------|--------|
| `scripts/sysinfo.sh` | Диагностическая сводка о состоянии сервера | вручную |
| `scripts/backup.sh` | Резервное копирование с ротацией по сроку хранения | cron, ежедневно |
